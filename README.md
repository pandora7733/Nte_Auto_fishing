# Nte_Auto_fishing

NTE 자동 낚시 봇 (Windows 전용)

화면의 낚시 바를 이미지로 인식해서 **노란 표시가 민트 바 안에 머물도록 A/D 키를 자동으로 눌러 줍니다.** 낚시 전후의 키 입력, 클릭, 대기 같은 동작은 "알고리즘 단계"로 직접 짜서 계속 반복할 수 있습니다.

---

## 1. 설치

### 필요 사항
- Windows 10/11
- [Python 3](https://www.python.org/downloads/) — 설치할 때 **"Add python.exe to PATH"** 체크

### 다운로드
- **ZIP:** GitHub 페이지에서 `Code` → `Download ZIP`을 눌러 받고, 원하는 위치에 압축을 풉니다.
- **git:**
  ```bash
  git clone https://github.com/pandora7733/Nte_Auto_fishing.git
  ```

### 실행
`run_nte_fishing.bat`을 더블클릭하고 관리자 권한(UAC) 요청을 허용하세요.

- 처음 실행할 때 `venv` 가상환경 생성과 패키지 설치가 자동으로 진행됩니다(1~2분 소요).
- 다음부터는 바로 실행됩니다.
- 관리자 권한이 없으면 키 입력이 게임에 전달되지 않을 수 있습니다. bat 파일이 자동으로 관리자 권한을 요청합니다.

### 바탕화면 바로가기 만들기 (선택)
프로젝트 폴더에서 PowerShell을 열고 아래 명령을 실행합니다.
```powershell
powershell -ExecutionPolicy Bypass -File .\create_shortcut.ps1
```
바탕화면, 시작 메뉴, 프로젝트 폴더에 `NTE_AutoFishing` 바로가기가 생깁니다. 프로젝트 폴더를 옮겼다면 다시 실행하세요.

| 하단 버튼 | `캡처 영역 지정`, `시작 (Start)`, `정지 (Stop)` |

## 3. 사용 방법

> 게임을 먼저 켜고, 낚시 미니게임 화면을 띄울 수 있는 상태에서 진행하세요.

### ① 실행 창 지정
- **`NTE 자동`**: 게임 창(프로세스 `HTGame`, 또는 제목이 `NTE`로 시작하는 창)을 자동으로 찾아 지정합니다.
- **`창 목록`**: 열려 있는 창 목록에서 직접 고릅니다. `[HTGame] NTE` 항목을 선택하면 됩니다.
- 지정하지 않고 시작하면 봇이 NTE 창을 한 번 자동으로 찾아봅니다.

### ② 캡처 영역 지정
1. 게임에서 낚시 바가 보이는 상태를 만듭니다.
2. **`캡처 영역 지정`**을 누르면 화면이 반투명해집니다.
3. 낚시 바 전체가 들어가도록 드래그합니다. 취소하려면 `Esc`를 누르세요.
4. 지정이 끝나면 미리보기가 시작됩니다.

> 영역은 낚시 바보다 조금만 넓게 잡으세요. 너무 넓으면 다른 물체를 잘못 인식할 수 있습니다.

### ③ 템플릿 확인 / 캡처
템플릿은 인식 기준이 되는 작은 이미지입니다. `templates/` 폴더에 기본 템플릿 3개(`mint_long.png`, `mint_short.png`, `yellow.png`)가 들어 있습니다.

먼저 미리보기에서 민트와 노랑에 박스가 잘 잡히는지 확인하세요. 잘 잡히지 않으면 직접 다시 캡처합니다. 해상도나 화면 배율이 다른 PC라면 다시 캡처해야 할 가능성이 큽니다.

| 버튼 | 캡처할 대상 | 저장 파일 |
| --- | --- | --- |
| `민트(긴) 캡처` | 긴 민트 바 | `templates/mint_long.png` |
| `민트(짧은) 캡처` | 짧은 민트 바 | `templates/mint_short.png` |
| `노랑 캡처` | 노란 표시 | `templates/yellow.png` |

- 버튼을 누른 뒤 해당 부분만 **작게** 드래그하면 저장됩니다. 저장하는 즉시 기존 파일을 덮어씁니다.
- `templates/` 폴더에서 이름이 `mint`로 시작하는 이미지는 모두 민트 템플릿으로, `yellow`로 시작하는 이미지는 모두 노랑 템플릿으로 불러옵니다. 그중 점수가 가장 높은 템플릿을 사용합니다.

### ④ 매칭 임계값 조절
슬라이더 범위는 0.40 ~ 0.95이고 기본값은 0.70입니다. 일치도 점수가 이 값 이상이어야 "감지됨"으로 판단합니다.
- **감지가 안 될 때:** 값을 낮추세요.
- **엉뚱한 곳을 잡을 때:** 값을 높이세요.

미리보기 상단에는 `Mint:좌표 (점수)`, `Yellow:좌표 (점수)`, `thr:임계값`이 표시되니 조절할 때 참고하세요.

### ⑤ 알고리즘 단계 만들기
**`단계 추가`**를 누르고 단계 종류를 고릅니다.

| 단계 | 동작 |
| --- | --- |
| `Sleep (타이머)` | 입력한 시간(초) 동안 기다립니다 |
| `Esc 키` | Esc 키를 한 번 누릅니다 |
| `F 키` | F 키를 한 번 누릅니다 |
| `마우스 클릭 (십자가)` | 화면에 십자가가 나타나면 클릭할 위치를 찍어 둡니다. 실행할 때 그 위치를 클릭합니다 |
| `낚시 (바 소실까지)` | 낚시 바를 추적하면서 A/D를 자동으로 누릅니다. 바가 사라지면 다음 단계로 넘어갑니다 |

- 단계는 목록 순서대로 실행되고, 마지막 단계가 끝나면 **처음부터 다시 반복**합니다.
- `▲ 위로`, `▼ 아래로` 버튼으로 순서를 바꾸고, `삭제`로 지웁니다.
- `낚시` 단계를 추가하려면 캡처 영역과 민트·노랑 템플릿이 먼저 준비되어 있어야 합니다.

**예시 구성** (게임 화면 흐름에 맞게 순서와 시간을 조정하세요)
```
[0] key F              ← 낚시 시작
[1] sleep 2.0s         ← 바가 나타날 때까지 대기
[2] fish (바 소실까지)  ← 자동 조작
[3] sleep 2.0s         ← 결과 화면 대기
[4] key ESC            ← 결과 화면 닫기
[5] sleep 1.0s
```

### ⑥ 시작 / 정지
- **시작:** `시작 (Start)`을 누르면 봇 창이 숨겨지고 게임 창이 앞으로 나온 뒤 단계 실행이 시작됩니다.
- **정지:** **`F8`** 키를 누르세요. 봇 창이 숨겨진 상태라 `정지` 버튼은 보이지 않습니다. 정지하면 봇 창이 다시 나타납니다.
- 실행 중에는 실행 창 변경, 템플릿 캡처, 단계 수정을 할 수 없습니다.

## 4. 낚시 단계의 동작 원리
1. 캡처 영역을 계속 캡처하고, 템플릿 매칭(OpenCV)으로 민트 바와 노란 표시의 X 좌표를 찾습니다.
2. 노랑이 민트보다 왼쪽에 있으면(5px 초과) **D**를 누르고, 오른쪽에 있으면 **A**를 누릅니다. 거의 같은 위치면 두 키를 모두 뗍니다.
3. 바가 한 번 감지된 뒤, 민트와 노랑이 모두 연속 15번(약 0.3초) 보이지 않으면 낚시가 끝난 것으로 보고 다음 단계로 넘어갑니다.

## 5. 주의 사항
- **설정은 저장되지 않습니다.** 프로그램을 닫으면 알고리즘 단계, 캡처 영역, 실행 창 지정, 임계값이 모두 초기화됩니다. 템플릿 이미지만 `templates/` 폴더에 남습니다.
- 캡처 영역과 마우스 클릭 위치는 **화면 절대 좌표**로 기억합니다. 실행 중에는 게임 창을 옮기거나 크기를 바꾸지 마세요.
- 해상도, 화면 배율(DPI), 게임 창 크기가 바뀌면 캡처 영역과 템플릿을 다시 지정하세요.

## 6. 문제 해결

| 증상 | 해결 방법 |
| --- | --- |
| 키 입력이 게임에 안 먹힘 | 상단에 `권한: 관리자 OK`가 표시되는지 확인하세요. 아니면 `run_nte_fishing.bat`으로 다시 실행하세요 |
| 민트/노랑이 감지되지 않음 (`-` 표시) | 템플릿을 다시 캡처하거나 임계값을 낮추세요. 캡처 영역 안에 바가 들어 있는지도 확인하세요 |
| 엉뚱한 위치를 감지함 | 임계값을 높이거나 캡처 영역을 바 주변으로 좁히세요 |
| 낚시 단계가 너무 일찍 끝남 | 바가 나타나기 전에 낚시 단계가 시작된 것일 수 있습니다. 앞의 `sleep` 시간을 늘려 보세요 |
| `HTGame(NTE) 창을 찾지 못했습니다` | 게임이 켜져 있는지 확인하고, `창 목록`에서 직접 선택하세요 |
| `Python이 설치되어 있지 않습니다` | Python 3을 설치할 때 "Add python.exe to PATH"를 체크했는지 확인하세요 |
| 패키지 설치 실패 | 인터넷 연결을 확인하세요. 그래도 안 되면 `venv` 폴더를 지우고 다시 실행하세요 |

## 7. 디버그 스크립트 (`index_debug.py`)
메인 프로그램과는 별개인 색상(HSV) 인식 테스트 도구입니다. 창 3개(원본+추적선, 민트 마스크, 노랑 마스크)를 띄우고, 감지된 좌표를 콘솔에 출력합니다.
```bash
venv\Scripts\python.exe index_debug.py
```
- 캡처 영역이 코드에 고정되어 있습니다(`left=500, top=100, 800x50`). 필요하면 코드에서 직접 수정하세요.
- **실제로 A/D 키를 누릅니다.** 눈으로만 확인하려면 해당 부분을 주석 처리하세요.
- 종료하려면 디버그 창을 선택한 상태에서 `Q`를 누르세요.
